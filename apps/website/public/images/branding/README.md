# Branding Assets

This folder stores the original branding assets for Sandtongrid Technologies.

## Purpose

Keep the original, high-resolution source files here. Generated assets (favicons, PWA icons, Open Graph images, etc.) should be created from these originals.

## Recommended files

- logo.svg
- logo-dark.svg
- logo-light.svg
- logo.png (high resolution)
- brand-guidelines.pdf (optional)

## Generated assets

The following files should remain in the root `public/` directory because browsers and search engines expect them there:

- favicon.ico
- favicon-16x16.png
- favicon-32x32.png
- apple-touch-icon.png
- android-chrome-192x192.png
- android-chrome-512x512.png
- og-image.jpg
- twitter-image.jpg
